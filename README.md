# Werte-Reflexion App

Einfache, barrierearme Web-App für Führungskräfte der Bundesverwaltung.

## Funktionen

- Wöchentlich (Montag-basiert) generierte Reflexionsfrage.
- Fokus auf die Werte: **Mut**, **Weitsicht**, **Vertrauen**.
- Eingabefeld für End-of-Week-Reflexion mit lokaler Speicherung.
- Kurzes automatisches Feedback zur eingegebenen Reflexion.
- Einfaches Design mit WCAG-orientierten Grundlagen:
  - klare Kontraste,
  - sichtbare Fokuszustände,
  - Skip-Link,
  - semantische Struktur und Labels.

## Lokal starten

```bash
python3 -m http.server 8000
```

Dann im Browser öffnen: <http://localhost:8000>
